# Animated Thumbnail Generator

Upload `.mp4`, `.mov`, `.mkv`, `.avi`, or `.webm` videos — get animated `.webp` thumbnails back.

- **Bulk upload** — drop multiple videos at once
- **Auto scene detection** — picks interesting moments automatically
- **Fallback** — evenly-spaced frames for low-cut videos
- **Download** — one by one or all at once

Built with FastAPI + FFmpeg.
